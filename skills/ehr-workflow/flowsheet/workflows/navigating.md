# Navigating Through Flowsheets (sections, subtabs, time)

> Companion to `skills/ehr-workflow/flowsheet/SKILL.md`. Read this file when your task involves **moving around a flowsheet** — by sections/subtabs (collapse, hide empty rows) or by time (pages, Admit column, Now Column, Enter Time).
> Source: EHR Online Help `Flowsheet_Screen_Features/Navigating_Flowsheets.htm`.
> Screen structure context: [screen-features.md](screen-features.md). Jumping to / adding specific columns is also covered in [rows-columns.md](rows-columns.md).

## Navigating by sections

- A flowsheet may have many **sections**, separated by **dark blue section headers** with the section name.
- Each section has a corresponding **subtab** just above the toolbar icons:
  - Select a subtab (e.g. **Pain**) to **jump to that section**. The selected subtab is **highlighted in gold**.
  - If there are too many subtabs to fit, select the **Subtabs menu** icon following the last subtab, then pick the subtab in the menu that displays. Select elsewhere on the screen to close the menu.
- Sections **default to expanded** so you can see the content:
  - **Collapse** a section: select the section header or the **Collapse** icon.
  - **Expand** a section: select the header again or the **Expand** icon.
- To **hide empty rows** within sections: select the **Hide Empty Rows** icon; select the **Show Empty Rows** icon to display them again.

## Navigating by time

Use these icons/features to move through the flowsheet in time:

- **Prev** / **Next** icons → move to the **previous / next page** of flowsheet data.
- **Admit Time** button → jump to the **Admit column** (the ADMIT column, if configured — see [screen-features.md](screen-features.md)).
- **Scroll bars** → move up/down and right/left.
- **Now Column** icon (depends on flowsheet configuration) does one of:
  - **Jump** to the top of the hour column for the **current time** — e.g. selecting it in the MAR at 0917 takes you to the **0900** column; or
  - **Create a column** for the current hour and minute — e.g. selecting it in a flowsheet at 0917 **adds a column for 0917**.
- **Enter Time** icon → view patient data for a **specific time and date**, or **insert a new time & date column** to chart on:
  1. In the **Column Time & Date** dialog, enter the time and date, or select the **Calendar** icon to choose date and time, or select **Now**.
  2. Select **Done** to jump to that column in the flowsheet.
