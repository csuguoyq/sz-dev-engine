# Tips for Working with Flowsheet Data (entry & save)

> Companion to `skills/ehr-workflow/flowsheet/SKILL.md`. Read this file when your task involves **entering, correcting, or discarding data in flowsheet cells** — the general keyboard/save mechanics that apply across charting workflows.
> Source: EHR Online Help `Working_with_Flowsheets/Tips_for_Working_with_Flowsheet_Data.htm`.
> Cell-type-specific entry rules: [data-cell-types.md](data-cell-types.md).

- **After selecting or typing in data, press ENTER.**
- **Multiple dropdown selections**: select multiple items, or type the dropdown number and press the **+** key between selections (e.g. `1+2+3`); press ENTER when finished. Multiple selections are **separated by a semicolon**.
- **Clear data not yet stored** from a data cell: press **SPACEBAR**, **BACKSPACE**, or **DELETE** in the data cell, then press **ENTER**.
- **Change stored data**: type the new data over the original, or press **SPACEBAR / BACKSPACE / DELETE** to remove all the data, press **ENTER**, and **save**. A **black triangle** displays in the right upper corner of the cell to indicate the data was **changed or deleted** ([symbols.md](symbols.md)).
- **Discard all un-stored entries**: either **exit the screen without saving**, or select the **Refresh Flowsheet** icon and select **Discard Changes** in the **Unsaved Data** dialog.
- **Save periodically**: be sure to store your changes by selecting the **Save** icon (per configuration a Validation dialog may require credentials — see [SKILL.md](../SKILL.md) §3).

## Unsaved-data cue

While you have un-stored edits, cells show a **dark outline** and the flowsheet tab shows a **black dot** after its title — see [symbols.md](symbols.md).
