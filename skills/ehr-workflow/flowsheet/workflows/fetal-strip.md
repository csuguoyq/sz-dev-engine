# Opening a Fetal Strip Screen from a Flowsheet

> Companion to `skills/ehr-workflow/flowsheet/SKILL.md`. Read this file when your task involves the **Fetal Strip split pane** at the bottom of a flowsheet (viewing one or two patients' fetal strips).
> Source: EHR Online Help `Working_with_Flowsheets/Opening_a_Fetal_Strip_Screen_from_a_Flowsheet.htm`.

> ⚠️ **Only one split pane feature works at a time** — for example, when the **I&O split pane** feature is active, the **Fetal Strip** split pane feature is disabled (see [io-split-pane.md](io-split-pane.md)).

On certain flowsheets you can open up to **two Fetal Strip screens** at the bottom of the flowsheet window:

1. **Show the strip**: select the **Show Fetal Strip** icon → the fetal strip displays at the **bottom of the screen**. (Viewing/navigating fetal strips is covered by the separate Fetal Strips help section.)
2. **Add a second patient's strip** (view at the same time):
   - Select the **Split Pane** icon and select the patient in the **dropdown list**.
   - If the second patient is **not currently being monitored**, the pane displays that patient's **latest stored strip**; select the **Records** dropdown to choose another strip to view if desired.
   - To close the second pane: select the **Close** icon, **or select the Split Pane icon again**.
3. **Close the Fetal Strip screen**: select the **Show Fetal Strip** icon again.
