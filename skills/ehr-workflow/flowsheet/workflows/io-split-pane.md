# Opening the I&O from a Flowsheet (I&O split pane)

> Companion to `skills/ehr-workflow/flowsheet/SKILL.md`. Read this file when your task involves the **I&O split pane** displayed below a flowsheet (viewing/editing I&O alongside another flowsheet).
> Source: EHR Online Help `Working_with_Flowsheets/Opening_the_IO_from_a_Flowsheet.htm`.

> ⚠️ **Only one split pane feature works at a time** — for example, when the **Fetal Strip** split pane feature is active, the **I&O** split pane feature is disabled (see [fetal-strip.md](fetal-strip.md)).

If configured, the **I&O** can display in a **split pane at the bottom of the flowsheet**:

1. Select the **I&O** icon → the **I&O pane** displays below the flowsheet.
2. To **add or edit I&O values** in the split pane:
   - Select the desired **cell** (see the separate I&O help section for working with the I&O).
   - **Time-column syncing**: when selecting time columns, **both flowsheets highlight the selection** — e.g. selecting a column in the I&O split pane highlights the corresponding column in the Assessment flowsheet. If there is **no I&O time column** that falls within the chosen hour column in the other flowsheet, a **vertical reference line** displays between columns in the I&O.
3. Select **Save**.
   > ⚠️ **Save works separately for each open pane** — make sure your cursor is in a cell of the **respective pane** and then select Save.
4. To close the second pane: select the **Close** icon, **or select the I&O icon again**.
