# Adding & Editing an Annotation

> Companion to `skills/ehr-workflow/flowsheet/SKILL.md`. Read this file when your task involves **adding or editing an annotation** (textual comment) on a flowsheet data cell.
> Source: EHR Online Help `Working_with_Flowsheets/Adding_and_Editing_an_Annotation.htm`. Viewing annotations: [viewing-data.md](viewing-data.md).

An annotation is a **textual comment attached to a data cell**; once added, an in-cell **Annotation** icon displays in that cell ([icons.md](icons.md)).

## Add an annotation

1. **Select a data cell**.
2. Select the **Annotation** toolbar icon, **or right-click** and select **Annotation**.
3. **Type your annotation** and select **Accept**.
4. An **Annotation icon** displays in the data cell.
5. Select the **Save** icon, then select **OK** in the save dialog.

## Edit an annotation

1. **Select the annotated data cell**.
2. Select the **Annotation** icon.
3. Make your changes and select **Accept**.
4. Select the **Save** icon, then select **OK** in the Save Changes dialog.

## Notes

- Annotation symbol/cell cue: see [symbols.md](symbols.md); icon list: [icons.md](icons.md).
- Annotations can be added to individual ventilator cells too — see [ventilator-data.md](ventilator-data.md) ("Each cell allows an annotation").
- Long annotations/comments may be truncated by your site (default 250 characters, ellipsis + hover tooltip) — see [viewing-data.md](viewing-data.md) → Viewing a Comment.
