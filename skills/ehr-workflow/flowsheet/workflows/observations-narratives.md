# Charting an Observation or Narrative

> Companion to `skills/ehr-workflow/flowsheet/SKILL.md`. Read this file when your task involves **charting observations or narratives** in an Observation / Narrative flowsheet section, or reading their in-cell icons.
> Source: EHR Online Help `Working_with_Flowsheets/Charting_an_Observation_or_Narrative.htm`.

If a flowsheet includes an **Observation** or **Narrative** section, you can chart observations or narratives **in that section's columns** (per time & date column).

## Chart an observation

1. **Double-click in the data cell** → the **Edit Observations** dialog opens.
2. **Select an item from the dropdown**, or **enter text**, and select **OK**.
3. Select **Save** (the **Save** icon).
4. Result: **the entry and an observation icon** display in the cell:
   - **Maternal patient** → Observation icon is **heart-shaped**.
   - **Other patients** → Observation icon is a **round blue circle**.
   - **Hover** over the icon to view a tooltip with the observation details.

## Chart a narrative

1. **Double-click in the data cell** → the **Narrative** dialog opens.
2. **Enter your text** and select **Save** (then the **Save** icon).
3. Result: the **Narrative icon** displays in the cell; **hover** over it to view a tooltip listing the narrative.
4. If configured, you can view the description in the **Summary Grid** (you may need to select the **Expand** icon following the last visible column to view it — see [screen-features.md](screen-features.md)).
