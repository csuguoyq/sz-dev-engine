# Working with Medical Devices in Flowsheets

> Companion to `skills/ehr-workflow/flowsheet/SKILL.md`. Read this file when your task involves **medical-device (make/model) sections** in a flowsheet — selecting a device make/model, or understanding how interfaced device detail imports.
> Source: EHR Online Help `Working_with_Flowsheets/Working_with_Medical_Devices_in_Flowsheets.htm`. Monitor import mechanics: [monitor-data.md](monitor-data.md); ventilator-specific flowsheet: [ventilator-data.md](ventilator-data.md).

- Flowsheets support **Medical Device sections**. You can identify the device **make and model** so interfaced detail can import automatically with the **Read Monitor** icons ([monitor-data.md](monitor-data.md)).
- Make/Model choices listed **in brackets do not automatically interface** — you can enter data for them **manually**.
- **Device rows that display are specific to the make/model selection** (rows for the chosen device).
- When **any Read Monitor icon** is engaged on the selected flowsheet, **all data from interfaced medical devices** for that flowsheet load and display **in italics** for that patient ([symbols.md](symbols.md)).
- ⚠️ **Calculated values may display in italics** even when they were generated from manually entered values (see [data-cell-types.md](data-cell-types.md) → Calculations).
